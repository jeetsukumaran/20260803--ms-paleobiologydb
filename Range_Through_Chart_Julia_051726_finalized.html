Range Through Chart and Diversity Curves in PaleobiologyDB (Coded in Julia)

Author

Jeet Sukumaran and Maritza Sardina

The original tutorial for “Range Through Chart and Diversity Curves Lab” was made possible by Katherine Bulinski from Bellarmine University, and was originally published on June 4th, 2009. This tutorial incorporates the original tutorial using a mix of both Julia code and written questions, as well as use of the PaleobiologyDB’s Navigator tool and the Sepkoski curve as a reference. This tutorial can be accessed at https://serc.carleton.edu/NAGTWorkshops/paleo/activities/33101.html.

Major events have occurred throughout geological history, “[including] the Cambrian explosion, the Ordovician Radiation, mass extinction events [”Big Five”], and more” (Bulinski, 2009). Many of these events can be analyzed and reconstructed in ways that measure biodiversity, or specifically the changes in worldwide diversity over geological time. For instance, the Sepkoski curve measures the biodiversity of numerous datasets and fossil records through time, which is done by counting the number of families in marine ecosystems throughout history and the changes that occur in their biodiversity. For more information, this curve can be accessed at https://silurian-reef.fieldmuseum.org/narrative/474, and it should be used in conjugation with your data in answering the questions at the bottom.

The main goal of this tutorial is to establish familiarity with twenty groups of organisms that have existed throughout geological time, knowledge about the paleontologic events throughout history, and understanding about the basics, commands, and functions of the Julia programming interface. Furthermore, you should interpret the results of your data and visualizations to the best of your ability when answering the questions indicated throughout the tutorial.

Evaluating the range of all fossil occurrences for our fossils of interest

To evaluate the exact range of Edrioasteroidea fossil occurrences, we will use pbdb_occurrences once more to create a new range-through chart that evaluates the range and diversity of Edrioasteroidea fossils over time. Firstly, we would want to retrieve our raw data by setting up our environment with all necessary packages and setting up auto-caching. This specifically allows us to retrieve our data and to save it in our local REPL. As such:

using PaleobiologyDB, PaleobiologyDB.Taxonomy, DataFrames
using Makie, CairoMakie, GeoMakie, ColorSchemes

PaleobiologyDB.set_autocaching!(true);

occs_edri_raw = pbdb_occurrences(
    base_name = "Edrioasteroidea",
    show = "full",
    vocab = "pbdb"
)

Then, we would want to clean up our data using dropmissing (via DataFrames) to drop any missing values and drop_unresolved_taxa (through the Taxonomy module of PaleobiologyDB.jl) to drop all unresolved taxa in our DataFrame, specifically for our genera. To ensure that our data is clean, we will use this code:

occs_edri = dropmissing(occs_edri_raw, [
    :genus,
    :early_interval,
    :max_ma,
    :min_ma
])

occs_edri = drop_unresolved_taxa(occs_edri, :genus)

Next, we will need to calculate a midpoint age (Ma) for each Edrioasteroida fossil occurrence, which we can do by creating a new code that calculates the midpoint age by dividing a sum of maximums and minimums by two, via arithemtic operations. Then, we will sort out our data using sort to include a new row for our calculated midpoint ages. This code is as follows:

occs_edri.midpoint_age = (occs_edri.max_ma .+ occs_edri.min_ma) ./ 2

occs_edri = sort(occs_edri, [:genus, :midpoint_age])

To calculate our range through values, we will be using the split-apply-combine method. This method is a type of coding workflow that splits a bigger DataFrame (consisting of all fossil occurrences for our genera/species) into per-genus specific tables consisting of first appearance and last appearance data. This is done by applying a summary function to each sub-table and combining them to form a new DataFrame, as follows:

appearance_occs_edri = combine(
    groupby(occs_edri, :genus, sort = true),
    :midpoint_age => maximum => :first_appearance_datum,
    :midpoint_age => minimum => :last_appearance_datum
)

Before we can plot our diversity curve for Edrioasteroidea (and our other fossils), we will need to again sort our data by the data of first appearance for each occurrence (:first_appearance_datum) in a reverse order. This allows us to chart our data from oldest appearances to the most recent appearances.

appearance_occs_edri = sort(appearance_occs_edri, :first_appearance_datum, rev=true)

We will be manually creating DataFrames for both Edrioasteroidea and the other nineteen fossils of interest to ensure that everything is properly graphed on each range through chart, and subsequently, for the overall diversity curve graph. Ensure that you are using different variable names for each of the fossils. As such:

using DataFrames

range_through_chart_edri = DataFrame(
    genus = appearance_occs_edri.genus,
    first_appearance_datum = appearance_occs_edri.first_appearance_datum,
    last_appearance_datum = appearance_occs_edri.last_appearance_datum
)

To create a range-through chart for Edrioasteroidea, we will use both “Makie” and “CairoMakie” to create a figure and a single axis, as well as a loop function to plot the range of each Edrioasteroidea genus through index number i and components x1 and x2 for both first and last appearance data. The code for creating the chart is as follows:

using Makie, CairoMakie, ColorSchemes

fig = Figure(size = (800, 700))
ax = Axis(
    fig[1,1],
    xlabel = "Midpoint age (Ma) of Edrioasteroidea genera",
    ylabel = "Genera",
    yticks = (1:nrow(appearance_occs_edri), appearance_occs_edri.genus),
    yticklabelsize = 7,
    title = "Ranges and diversity of Edrioasteroidea genera",
    xreversed = true
)

for i in 1:nrow(appearance_occs_edri)
    x1 = appearance_occs_edri.first_appearance_datum[i]
    x2 = appearance_occs_edri.last_appearance_datum[i]
    lines!(ax, [x1, x2], [i, i], colorscale = :auto)
end

Part 2: Constructing a Diversity Curve

Preparation by counting diversity per geographical interval

We will now use pbdb_occurrences to retrieve data for our fossil occurrences (using Edrioasteroidea again as our example) and to proceed into the same steps for cleaning up our data. PBDB.Taxonomy is also used (as a module apart of “PaleobiologyDB.jl”) to drop any unresolved or unqualified taxa from our data. The code for these next few steps are as follows:

using PaleobiologyDB, DataFrames, CairoMakie, GeoMakie
PaleobiologyDB.set_autocaching!(true);

df_edri_diversity_raw = pbdb_occurrences(
    base_name = "Edrioasteroidea",
    show = "full",
    vocab = "pbdb"
)

df_edri_diversity = dropmissing(df_edri_diversity_raw, [
    :genus,
    :early_interval,
    :max_ma,
    :min_ma
])

df_edri_diversity = Taxonomy.drop_unqualified_taxa(df_edri_diversity, "genus")

We will then calculate our midpoint age (Ma) and use the split-apply-combine method to create a table of geographical intervals using a standard binning method. Specifically, we will be grouping, naming, and summarizing the representative age bounds of each of our fossil occurrences from oldest to youngest (using the sort function to align all ages in a reverse order). The code for these next few steps is below:

df_edri_diversity.midpoint_age = (df_edri_diversity.max_ma .+ df_edri_diversity.min_ma) ./ 2

interval_df_1 = combine(
    groupby(df_edri_diversity, :early_interval),
    :max_ma => maximum => :interval_max_ma,
    :min_ma => minimum => :interval_min_ma,
)

interval_df_1.interval_mid_ma = (
    interval_df_1.interval_max_ma .+ interval_df_1.interval_min_ma
) ./ 2

interval_df_1 = sort(interval_df_1, :interval_mid_ma, rev=true)

Next, we will be finding the first appearance and last appearance data for each of our genera in Edrioasteroidea by taking both the maximum and minimum ages per fossil occurrences. As such, this can be done by using the split-apply-combine method, as seen below:

genus_ranges_of_edri = combine(
    groupby(df_edri_diversity, :genus),
    :midpoint_age => maximum => :fad_ma,
    :midpoint_age => minimum => :lad_ma,
)

Now, we will create a diversity curve for all genera belonging to Edrioasteroidea using a for... end argument, which creates flow control using the index number i (which refers to both the rows and the y-axis). This serves to count one diversity number per geographical interval and to collect them inside a vector, as shown below:

diversity = Int[]

for interval_row in eachrow(interval_df_1)
    n = count(
        g -> g.fad_ma >= interval_row.interval_mid_ma >= g.lad_ma,
        eachrow(genus_ranges_of_edri)
    )
    push!(diversity, n)
end

interval_df_1.diversity = diversity

Plotting a diversity curve

For this particular graph, since there are so many fossils of interest (per this tutorial), we will be splitting the graph into four separate axes. This can be done by using the ‘Axis’ function via the “Makie” family of packages and by changing the numbers in the fig attribute (e.g., fig[1,1] to indicate an axis to the left). We will need 20 axes total (from ax1 to ax20), so five axes will be put into each new figure (e.g., fig) for a total of four big graphs. hidedecorations! is used to hide the descriptions for both x- and y-axes, as well as certain attributes pertaining to the graph, which is crucial for these types of graphs, since we don’t want to overwhelm our visualization with too much cramped information. As seen in the code below, twenty different lines! arguments and twenty different scatter! arguments are to be used to plot each DataFrame (as established in the previous section) separately, and by each different color.

For reference, the code below mainly consists of commands previously established throughout the tutorial. Additionally, many components were copied-and-pasted manually by keyboard shortcuts to show repetition of the functions needed for the graph. Why are we doing all of this?

The main goal of making these diversity curves is to measure changes in biodiversity between different geospatial intervals and events in geological history for different taxonomic ranks.
