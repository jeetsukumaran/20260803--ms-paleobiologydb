Major events in paleontological history have resulted in changes in the biodiversity of numerous species, genera, and major groups of organisms. Many fossils belonging to these groups can be found using PaleobiologyDB’s Navigator tool through fossil sites scattered across the world. This is thanks to the vast availability of resources like Navigator and the Internet, which allow us to access records of these fossil occurrences almost immediately. One such goal of this research is to detect and configure ways to reduce or resolve problems surrounding biodiversity changes in our modern world (Fronimos and Novack-Gottshall, 2018).

Hence, the goal of this tutorial is to grow familiarity with both Navigator and the Julia environment (for your coding sections), and to test hypotheses about these major events and changes in diversity using these resources. This includes creating a diversity curve that pertains to diversity and interval data regarding three marine groups of organisms on the sea floor.

Before we begin analyzing our data, we’ll use the command pbdb_collection to obtain the exact geospatial details about our collection and its location using this code:

collection_pk = pbdb_collection("col:178006", show = ["loc", "stratext"], extids = true)

show(describe(collection_pk), allrows = true)

A show command is used in conjugation with the describe command to list all rows and miscellaneous details about the DataFrame we’ve generated using pbdb_collection. Now, you’ll need to call our data using pbdb_occurrences, with the species name being represented by its base_name. The “;” used in the code below represents the separation of a syntax argument from a keyword argument, and it might be useful for suppressing certain outputs from forming (although it isn’t always used). Contrary to popular belief, putting in a limit (e.g., limit = 1000) might not be as useful, as it might greatly warp our data to fit certain biases in research. Thus, our code will be:

occs = pbdb_occurrences(
    ;
    base_name = "Puffinus kanakoffi",
    show      = "full",
    vocab     = "pbdb",
    extids    = true
)

There are several commands that can be used to describe and show the data for P. kanakoffi, such as show, foreach, describe, and more. foreach is used with two arguments (println and names(occs)) to list the columns of the entire DataFrame. describe is typically used to summarize the DataFrame with column names, element types, and other descriptors. ‘show’ (with the additional function of allrows=true) is used to list everything from the DataFrame.

As such:

foreach(println, names(occs))

describe(occs)

show(describe(occs), allrows=true)

With the combine and groupby functions, we can see how the fossil records for P. kanakoffi are distribued across different taxonomic ranks.

combine(groupby(occs, :accepted_rank), nrow)

Through this output, there are only 11 records within the entire collection, which greatly contrasts the collections typically seen in San Diego (our example) with other more diverse collections from around the world. Specifically, a collection of fossils (particularly in one site) is always just a singular datum, so it might help to broaden your research to entire different collections. In order to filter out the DataFrame to solely include species and sub-species occurrences, we can filter out the data using ‘filter’, which only keeps certain rows fitting that condition.

clean_taxonomy_flt =
   row -> row.accepted_rank == "species" || row.accepted_rank == "subspecies"

occs_mon_species = filter(clean_taxonomy_flt, occs_mon)

This should give you a filtered DataFrame with solely species and sub-species occurrences, which were filtered out using a custommade function within a labeled variable called clean_taxonomy_flt. Now, to calculate direct midpoint age (Ma) measurements for these filtered fossil occurences, we can select these ranges using the following code:

occs_mon_species[:, r".*_ma.*"]

This is an example of regular expressions in Julia. For context, a regular expression is a string of characters and symbols used to search and match certain patterns within our DataFrame. Along with a colon, “:”, to ensure that the function applies to every row, this sequence of characters (beginning with “r…”) is asking us to search for and match to every single column with the pattern “_ma” representing midpoint age. Hence, this type of expression converts strings of text into viable outputs that we can analyze from.

With this in mind, this should give you another filtered DataFrame with only the columns that include the midpoint age (Ma) measurements for filtered fossil occurrences of Mollusca. To check how many direct MA and MA error measurements are present, you can use println to determine which age columns for your fossil occurrences to use. “direct_ma_value” represents the highest precision, but the lowest coverage for your occurrences. “max_ma” and “min_ma” bracket the precise age range for your occurrences, which ensures broader coverage. “ma_error” represents the uncertainty for your occurrences and their age columns/measurements. In this case, we will be sticking to just “max_ma” and “min_ma”.

println("Max MA measurements: ", nrow(dropmissing(occs_mon_species, r".*max_ma.*")))
println("Min MA measurements: ", nrow(dropmissing(occs_mon_species, r".*min_ma.*")))

In our scenario, we want to retain both “max_ma” and “min_ma” measurements for our fossil occurences.

occs_mon_ages = dropmissing(occs_mon_species,
    [:max_ma, :min_ma])

In terms of spatial completeness, we will need modern coordinates for our fossil occurrences. First, we’ll need to check the coverage for both kinds of coordinates using println, then we will retain both values to clean up our DataFrame with a new variable, like occs_clean. As such:

modern_coords = nrow(dropmissing(occs_mon_ages, [:lng, :lat]))
println("Records with modern coordinates:    ", modern_coords)

occs_mon_clean = dropmissing(occs_mon_ages, [:lng, :lat])

Finally, you can use your cleaned DataFrame to print out the number of different taxonomic records present for your species, using a plethora of functions previously mentioned. These include combine and groupby (to determine the distribution of taxonomic ranks in your chosen species), and println (to print out the number of records available for your species and its cleaned DataFrame). Part 3: Examining patterns through geological time (by creating diversity curves)

We will now be looking at sea floor fauna in the Paleozoic Era and in the modern-day continents. Back in the Paleozoic, the phylum Brachiopoda consisted of most of the fauna present, while in the modern-day world, Mollusca and Bivalvia fulfill most of the fauna present in the sea floor. For this part of the tutorial, we will be creating diversity curves for all three phyla to create a graph of diversity over geological time. pbdb_occurrences will be used to retrieve data for all three phyla, and the data will be cleaned and transformed in preparation for the next few steps. Using Brachiopoda as an example, the following code is:

using PaleobiologyDB, PaleobiologyDB.Taxonomy, DataFrames
using Makie, CairoMakie, GeoMakie, ColorSchemes

PaleobiologyDB.set_autocaching!(true);

occs_competition_raw_1 = pbdb_occurrences(
    base_name = "Brachiopoda",
    show = "full",
    vocab = "pbdb"
)

occs_competition_1 = dropmissing(occs_competition_raw_1, [
    :genus,
    :early_interval,
    :max_ma,
    :min_ma
])

occs_competition_1 = Taxonomy.drop_unqualified_taxa(occs_competition_1, "genus")

To calculate a midpoint age (Ma) for each fossil occurrence for Brachiopoda, we will use arithmetic operations, using a period mark (.) before each function (e.g., .+, ./) to ensure that the operation is applied to each element in the column. The midpoint age is calculated by taking the average of the maximum and minimum midpoint age values for each fossil occurrence, as follows:

occs_competition_1.midpoint_age = (
    occs_competition_1.max_ma .+ occs_competition_1.min_ma
) ./ 2

interval_competition_1 = combine(
    groupby(occs_competition_1, :early_interval),
    :max_ma => maximum => :interval_max_ma,
    :min_ma => minimum => :interval_min_ma,
)

As shown above, combine and groupby functions were used to group the data per geological intervals. Now, we will calculate midpoint ages (Ma) for each interval, using the same workflow as before. Then, we will use another combine and groupby function combination to group the data based on genera belonging to Brachiopoda. This is shown as follows:

interval_competition_1.interval_mid_ma = (
    interval_competition_1.interval_max_ma .+ interval_competition_1.interval_min_ma
) ./ 2

interval_competition_1 = sort(interval_competition_1, :interval_mid_ma, rev=true)

genera_competition_1 = combine(
    groupby(occs_competition_1, :genus),
    :midpoint_age => maximum => :fad_ma,
    :midpoint_age => minimum => :lad_ma,
)

Now, we will create a diversity curve for all genera belonging to Brachiopoda using a for... end argument, which initiates flow control with index number i (referring to both the row and the y-axis). This serves to count one diversity number per interval and to collect them inside a vector, as follows:

diversity = Int[]

for interval_row in eachrow(interval_competition_1)
    n = count(
        g -> g.fad_ma >= interval_row.interval_mid_ma >= g.lad_ma,
        eachrow(genera_competition_1)
    )
    push!(diversity, n)
end

interval_competition_1.diversity = diversity

You’ll need to repeat this workflow for both Mollusca and Bivalvia while ensuring you use different variable names for each phylum (for the sake of distinguishing between them). Shown below is an example of how you can use the workflow for Mollusca:

Now, you can create a diversity curve using “Makie” family packages (e.g., “CairoMakie” and “Makie”) to create a three-line graph with each phylum represented by different colors. The x-axis will represent the age (Ma), while the y-axis represents the number of genera present per intervals for each phylum. The code for this is as follows:

using Makie, CairoMakie, ColorSchemes

fig = Figure(size = (1750, 550), fontsize = 11.5)
ax1 = Axis(
    fig[1,1],
    xlabel = "Age (Ma)",
    ylabel = "Number of genera",
    title = "Genus diversity of fossils from Brachiopoda,
        Mollusca, and Bivalvia through time",
    xticks = (interval_competition_1.interval_mid_ma,
        interval_competition_1.early_interval),
    xticklabelrotation = π/4,
    xticklabelsize = 4.5,
    xreversed = true,
)
ax2 = Axis(
    fig[1,1],
    xticks = (interval_competition_2.interval_mid_ma,
        interval_competition_2.early_interval),
    xticklabelrotation = π/4,
    xticklabelsize = 4.5,
    xreversed = true,
)
ax3 = Axis(
    fig[1,1],
    xticks = (interval_competition_3.interval_mid_ma,
        interval_competition_3.early_interval),
    xticklabelrotation = π/4,
    xticklabelsize = 4.5,
    xreversed = true,
)
hidedecorations!(ax2)
hidedecorations!(ax3)

lines!(ax1, interval_competition_1.interval_mid_ma,
    interval_competition_1.diversity, linewidth = 2, color = :orange)
scatter!(ax1, interval_competition_1.interval_mid_ma,
    interval_competition_1.diversity, markersize = 8, color = :orange, label = "Brachiopoda")

lines!(ax2, interval_competition_2.interval_mid_ma,
    interval_competition_2.diversity, linewidth = 2, color = :seagreen3)
